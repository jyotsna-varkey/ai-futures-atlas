# AI Futures Atlas

An interactive, source-linked framework for thinking about how AI reshapes the economy and society. Fourteen open questions, linked as a causal graph, lead to seven possible worlds. Each question carries today's measured readings and which way they lean.

## Files

- `index.html`: the current atlas (pink newsprint style). `Measured AI Futures Atlas.html` is a mirror of it.
- `index-signal.html`: the same atlas in the Signal style (grid paper, grey blocks, one signal orange).
- `index-measured-v17.html`: the earlier measured layout.
- `AI Futures Decision Atlas.html`: the original qualitative atlas.
- `signal_style_long_mockup.html`: the style reference for the Signal version.

Each page is one self-contained HTML file. Open it in a browser; no build step.
